## Learning Path

1. **Start with Windows fundamentals:** Become familiar with processes, services, registry structure, and event logs.
2. **Explore registry analysis:** Work through Registry Sleuth, Registry Explorer, Regedit Essentials, and Regshot.
3. **Study memory and process dumps:** Explore the WinPmem Memory Hunt and ProcDump Dump Detective labs.
4. **Investigate system activity:** Practice with Autorunsc and Event Log Sleuth.
5. **Continue with debugging and monitoring:** Explore both WinDbg labs, Portmon, and Pipe Whisperer.

Adjust the sequence to your existing Windows and cybersecurity experience.

## How to Use the Labs

1. Open a lab using its direct link above.
2. Review the lab objectives, requirements, and provided instructions.
3. Complete the exercises in the environment authorized by the lab.
4. Record your methodology, observations, and lessons learned.
5. Revisit challenging topics and document useful findings in your own notes.

Use a controlled lab environment for memory acquisition, debugging, registry modification, and system monitoring exercises.
